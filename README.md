# Bornite Sweep

Full-colour Python 3 neon minesweeper arcade for [ElbowOS](https://x.com/ElbowOS).

Clear an 8×11 peacock-ore grid. Numbers glow lime / cyan / magenta. Flag the bornite charges. WASD to move, Space to open, F to flag.

## Play

```
pip install -r requirements.txt
python3 bornite_sweep.py --play
```

## Record a 9:16 reel

```
python3 bornite_sweep.py --record
```

Writes a 15s 1080×1920 h264 MP4 (dummy SDL if no display).
